字段名 说明 必填
hero.titlehero 标题（首屏大标题，宋体展示字）必填
hero.subtitle副标题（档期一句话）必填
sessions场次列表（日期 / 时间 / 开售状态）必填
ticket_tiers票档（档位 / 价格 / 库存状态，价格与档位为示例）必填
notice购票须知（限购、入场证件等规则，规则文本为示例）必填
refund_policy退换规则（可退时限、手续费档位，规则文本为示例）必填
venue_info场馆信息（名称 / 交通提示）选填
geo地理位置（city / address / lat / lng，坐标缺失按城市名降级）必填
seat_map座位图（2D 为主，3D 线框为增强项）选填

三个实例共用同一套模板字段，仅内容不同；模板不含明星肖像 / 照片 / 品牌 logo 素材，视觉一律走文字 + 几何。
