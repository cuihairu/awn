# 源码拆分理由

[English](../../architecture/source-layer-split-rationale.md) | 中文 · [架构](source-layer-architecture.md) · [术语表](source-layer-glossary.md)

以下理由编号便于追溯。每条都指向 `7e43d70` 中已检视的源码行为。

1. **客户端渠道与可复用展示分离，因为它们消费同一 HTTP 契约，但传输层和页面生命周期不同。** web 依赖共享 API client、专场渲染器、票档组件和 UI 包（`apps/web/package.json:10-15`）；小程序使用自己的 Taro transport（`apps/miniprogram/src/lib/taro-transport.ts:10-37`）和页面路由（`apps/miniprogram/src/app.config.ts:1-32`）；Flutter 拥有 Dio 和原生模型类（`apps/client/lib/src/api/awn_client.dart:4-40`）。合并会让浏览器生命周期耦合 Taro/Dio。
2. **组合根独立，因为 HTTP 策略不是业务逻辑。** API 启动只为 HTTP（`apps/awn-api/src/main/java/site/awn/AwnApplication.java:6-17`）；追踪透传、API 认证和运营限流是 Servlet 过滤器（`apps/awn-api/src/main/java/site/awn/api/TraceIdFilter.java:14-55`; `apps/awn-api/src/main/java/site/awn/api/auth/ApiAuthenticationFilter.java:15-77`; `apps/awn-api/src/main/java/site/awn/api/AdminAuthFilter.java:29-96`），异常适配器再把显式暴露的领域异常翻译为 HTTP 语义（`modules/awn-order/src/main/java/site/awn/order/domain/package-info.java:1-6`; `apps/awn-api/src/main/java/site/awn/api/ApiExceptionHandler.java:16-101`）。
3. **业务模块独立，因为依赖和公共契约被显式定向。** Maven 模块列表声明业务模块（`pom.xml:26-46`），POM 记录实际跨模块边：catalog→event、inventory→catalog、marketplace→audit、order→inventory/marketplace/catalog、payment→order（`modules/awn-catalog/pom.xml`; `modules/awn-inventory/pom.xml`; `modules/awn-marketplace/pom.xml`; `modules/awn-order/pom.xml`; `modules/awn-payment/pom.xml`）。包注释只允许命名 API 接口和显式暴露的领域异常（`modules/awn-order/src/main/java/site/awn/order/api/package-info.java:1-6`; `modules/awn-order/src/main/java/site/awn/order/domain/package-info.java:1-6`）。
4. **模块内部再分应用、领域和持久化，因为稳定不变量与可替换适配器的变化速度不同。** 订单创建是应用服务事务（`modules/awn-order/src/main/java/site/awn/order/application/OrderWriteService.java:88-198`），位于订单状态机（`modules/awn-order/src/main/java/site/awn/order/domain/Order.java:14-132`）和 JPA 仓库（`modules/awn-order/src/main/java/site/awn/order/infrastructure/OrderRepository.java:13-44`）之上。支付创建沿用同一边界（`modules/awn-payment/src/main/java/site/awn/payment/application/PaymentFacadeImpl.java:88-130`）。
5. **共享后端基础设施独立，因为持久化单元和可靠消息横跨所有业务模块。** `awn-shared` 一起配置交易与情报的仓库扫描器和实体管理器（`modules/awn-shared/src/main/java/site/awn/shared/config/PersistenceConfig.java:43-96`）；发件箱认领、收件箱去重、重试、租约和失败告警构成一个可复用协议（`modules/awn-shared/src/main/java/site/awn/shared/outbox/OutboxMessage.java:14-86`; `modules/awn-shared/src/main/java/site/awn/shared/outbox/OutboxDispatchService.java:17-131`; `modules/awn-shared/src/main/java/site/awn/shared/inbox/InboxMessage.java:14-55`）。
6. **API 与 Worker 是不同运行层，因为 HTTP 与定时副作用的安全边界相反。** API 显式关闭 Worker 执行（`apps/awn-api/src/main/resources/application.yml:55-58`）；Worker 关闭业务 web 服务并启用调度（`apps/awn-worker/src/main/java/site/awn/worker/AwnWorkerApplication.java:6-27`）；每个任务独立检查全局/任务开关（`apps/awn-worker/src/main/java/site/awn/worker/task/OrderTimeoutTask.java:27-39`; `apps/awn-worker/src/main/resources/application.yml:43-61`）。
7. **数据独立成层，因为 PostgreSQL 权威与 Redis 选型保证不同。** 两个持久化单元把 `site.awn.intelligence` 仓库和事务与交易隔离（`modules/awn-shared/src/main/java/site/awn/shared/config/PersistenceConfig.java:43-96`）；迁移归属防止并发迁移（`apps/awn-api/src/main/resources/application.yml:22-31`; `apps/awn-worker/src/main/resources/application.yml:22-24`）；Redis 与内存是条件化限流实现，多实例保证不同（`modules/awn-shared/src/main/java/site/awn/shared/ratelimit/RedisRateLimiter.java:10-33`; `modules/awn-shared/src/main/java/site/awn/shared/ratelimit/InMemoryRateLimiter.java:10-17,35`）。
8. **部署独立，因为进程镜像、代理路由、后端存储、凭证和健康顺序都是运维关注点。** API 与 Worker 有不同多阶段 Dockerfile 和暴露端口（`deploy/docker/api.Dockerfile:5-41`; `deploy/docker/worker.Dockerfile:1-41`）；Caddy 按路径路由三个前端（`deploy/config/caddy/Caddyfile:4-20`）；Compose 分配交易/情报/迁移角色，并在 API 健康后才启动 Worker（`deploy/docker-compose.yml:52-73,96-106`）。
