座位数据模型（同一份数据，两种渲染器）

Venue（场馆身份）→ VenueLayoutVersion（基础布局版本：坐标系 / 原始资料 / 审核状态）→ Section（分区：多边形边界 / 名称 / 编号 / 楼层）→ RowRange（排号规则：起止排 / 编号方向 —— 仅在有可靠数据时维护）→ EventSeatingConfiguration（演出配置：舞台 / 开放区域 / 临时座席 / 分区↔票档映射）

边界：座位图 = 空间与编号，库存 = 可售状态，两者不是一个模型。座位图里有某座位 ≠ 该演出开放销售。

精度等级：L1 轮廓 / 看台 / 分区（本原型南、北看台即 L1，不虚构排号）· L2 分区 / 排号 / 座号（内场 A/B、东西看台）· L3 逐座精确几何 + 库存映射（后续）。
