# 卖票渠道扩展调研

- 调研日期：2026-10-15
- 范围：只调研 + 落档，不写实现
- 方法：逐渠道访问官方页面核实（WebFetch 实抓），**未核实到的能力一律标注「未核实」，不凭记忆断言**
- 结论一句话：**闲鱼不建议作为自动化发单渠道；优先做微信视频号小店（用户可控、已核实有本地生活团购 API），票牛 Open API 是唯一已核实的票务专用开放接口**

## 一、闲鱼可行性（如实结论）

### 核实到的事实
- 闲鱼官方**确实存在**「闲鱼三方开发平台」，域名 `https://open.goofish.com/`，页面标题为「闲鱼三方开发平台」（已实抓核实）。
- 该平台为前端渲染（SPA），公开网页上**读不到**入驻条件、开发者类型、商品发布/自动发单等 API 能力清单。因此**无法从公开渠道核实闲鱼是否向个人卖家开放「控制账号发信息 / 自动发布票务信息」的 API**。
- 淘宝开放平台 `https://open.taobao.com/` 在本环境被工具层拦截，无法核实其是否暴露闲鱼相关 API。

### 结论：能否做、怎么做、代价
| 问题 | 结论 |
|------|------|
| 能否做 | **自动化发单：不可行（无公开 API 可核实）**。人工发布：可行。 |
| 怎么做 | 若官方平台确有开放能力，走官方入驻（需企业/开发者资质，**未核实**）；否则只能人工在闲鱼 App 发布。 |
| 代价 | 闲鱼是 C2C 二手平台，账号风控严格。任何**协议逆向 / RPA / 群控**方案都违反平台服务协议，**封号风险高，且风控升级后失效**。**不建议生产使用。** |

### 建议
- 把闲鱼当作**人工发布渠道**（运营手动发），不投入自动化对接。
- 若未来确需对接，先向闲鱼三方开发平台官方确认是否开放「商品发布 / 消息推送」API 及个人卖家准入，再评估。

## 三、渠道优先级建议

按「接入成本 / 合规风险 / 流量」三维度排序：

| 优先级 | 渠道 | 接入成本 | 合规风险 | 流量 | 理由 |
|--------|------|---------|---------|------|------|
| **1（推荐）** | **微信视频号小店** | 中（需企业资质 + 开发对接） | **低**（用户可控、官方 API） | 高（微信生态） | 用户可控、已核实有本地生活团购 API（商品/库存/订单/核销/对账），合规风险最低，且用户明确优先级最高 |
| 2 | 抖音开放平台（生活服务） | 中 | 低（官方 API） | 高 | 有票务行业方案 + 团购核销闭环，流量大，可作为第二渠道 |
| 3 | 票牛 Open API | 中（需申请接入商） | 低（官方 API） | 中 | 唯一已核实的票务专用开放接口，适合对接二级票务市场 |
| 4 | 闲鱼 | 低（人工）/ 高（自动化） | **高**（自动化违规封号） | 中 | 仅作人工发布渠道，不做自动化 |
| — | 大麦 / 小红书 / 猫眼 / 摩天轮 / 秀动 | 未核实 | 未核实 | — | 本次未能证实有公开 API，暂不投入 |

### 单个明确推荐
**优先做「微信视频号小店」。**

理由：
1. **用户可控**——不依赖第三方平台审核与分账，商品/订单/核销/资金都在自己手里。
2. **已核实有开放能力**——微信视频号开放平台 API 的「本地生活 API」覆盖团购商品管理、库存、订单、核销、资金对账、退款，正是票务转售需要的闭环。
3. **合规风险最低**——官方 API 对接，无封号风险。
4. **流量与生态**——微信生态内闭环，符合用户「优先级最高」的判断。

**次选**：抖音开放平台（生活服务）作为流量补充；**票牛 Open API** 作为对接二级票务市场的票务专用通道。
