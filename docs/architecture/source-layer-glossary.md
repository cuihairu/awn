# Source Layer Glossary

English | [中文](../zh/architecture/source-layer-glossary.md)

This glossary defines the runtime concepts used by the source layer analysis. Paths and line numbers refer to the source inspected at commit `7e43d70`.

| Term | English | Definition | Evidence |
|---|---|---|---|
| 源码层 | Source layer | A responsibility boundary derived from inspected source: clients, shared packages, composition root, business modules, shared infrastructure, runtimes, data, and deployment. | `pom.xml:26-46`; `deploy/docker-compose.yml:15-104` |
| 客户端渠道 | Client channel | A user-facing process or bundle that owns screen state and local presentation; it calls HTTP but does not own trading state. | `apps/web/app/layout.tsx:7`; `apps/admin/src/App.tsx:17`; `apps/miniprogram/src/app.ts:17` |
| 共享前端包 | Shared frontend package | A workspace package reused by channels for API contracts, UI, ticket components, or campaign rendering. | `packages/api-client/src/index.ts:9`; `packages/ui/src/themes.ts:14`; `packages/campaign-renderer/src/index.ts:11` |
| API 客户端 | API client | The TypeScript client that fixes `/api/v1` as its default base, defines cross-channel DTOs, and normalizes non-2xx responses as `ApiError`. | `packages/api-client/src/index.ts:9,143-167` |
| 渠道传输适配器 | Channel transport | A channel-specific HTTP wrapper: browser `fetch`, Taro request, or Dio in Flutter. | `apps/miniprogram/src/lib/taro-transport.ts:10-37`; `apps/client/lib/src/api/awn_client.dart:15-55` |
| 本地文案 | Local copy | Channel-owned labels and page text stored in each app or component, not centralized in the backend. | `apps/web/app/layout.tsx:14-35`; `apps/admin/src/views/OrdersView.tsx:11-42`; `apps/miniprogram/src/pages/index/index.tsx:20-55` |
| 设计令牌 | Design token | Cross-app CSS/theme constants owned by `packages/ui`; `apps/web/app/globals.css` bridges its structural styles to these tokens. | `packages/ui/src/themes.ts:14-61`; `apps/web/app/globals.css:1-12` |
| 组合根 | Composition root | The Spring Boot API module that owns HTTP routes, request/response shapes, authentication, rate limiting, trace propagation, and mapping of domain exceptions to HTTP errors. | `apps/awn-api/src/main/java/site/awn/AwnApplication.java:6-17`; `apps/awn-api/src/main/java/site/awn/api/ApiExceptionHandler.java:55-101` |

| 固定窗口限流 | Fixed-window rate limit | A `RateLimiter` contract allowing at most N requests per key per window, implemented in memory by default and in Redis when configured. | `modules/awn-shared/src/main/java/site/awn/shared/ratelimit/RateLimiter.java:5-17`; `modules/awn-shared/src/main/java/site/awn/shared/ratelimit/RedisRateLimiter.java:10-33` |
| 追踪标识 | Trace ID | A validated `X-Request-Id` propagated through one HTTP request, or generated per Worker task. | `apps/awn-api/src/main/java/site/awn/api/TraceIdFilter.java:14-55`; `modules/awn-shared/src/main/java/site/awn/shared/trace/Traces.java:9-44` |

| 运行进程 | Runtime process | One deployable process with a distinct lifecycle: HTTP API or scheduled Worker. | `apps/awn-api/src/main/java/site/awn/AwnApplication.java:6-17`; `apps/awn-worker/src/main/java/site/awn/worker/AwnWorkerApplication.java:6-27` |
| 业务模块 | Business module | A Maven module with `api`, `application`, `domain`, and `infrastructure` packages; it owns its use cases and tables. | `modules/awn-order/src/main/java/site/awn/order/package-info.java:1-15`; `modules/awn-inventory/src/main/java/site/awn/inventory/package-info.java:1-15` |

| 公共接口 | Public interface | The `api` package contract through which controllers and Worker tasks invoke a module. | `modules/awn-order/src/main/java/site/awn/order/api/OrderFacade.java:7-42`; `apps/awn-worker/src/main/java/site/awn/worker/task/OrderTimeoutTask.java:8-41` |
| 领域异常 | Domain exception | A module-owned error contract deliberately exposed so the composition root can map it to HTTP semantics. | `modules/awn-order/src/main/java/site/awn/order/domain/package-info.java:1-6`; `apps/awn-api/src/main/java/site/awn/api/ApiExceptionHandler.java:16-53` |
| 应用服务 | Application service | The module layer that coordinates domain state, persistence, side effects, and transactions for one use case. | `modules/awn-order/src/main/java/site/awn/order/application/OrderWriteService.java:48-219`; `modules/awn-payment/src/main/java/site/awn/payment/application/PaymentFacadeImpl.java:51-148` |
| 领域模型 | Domain model | Module-owned entities, value objects, states, and invariants that survive application-service refactoring. | `modules/awn-order/src/main/java/site/awn/order/domain/Order.java:14-132`; `modules/awn-payment/src/main/java/site/awn/payment/domain/Payment.java:14-132` |
| 事务边界 | Transaction boundary | The transactional application-service method that commits business state and message records together. | `modules/awn-order/src/main/java/site/awn/order/application/OrderWriteService.java:88-198`; `modules/awn-payment/src/main/java/site/awn/payment/application/PaymentFacadeImpl.java:88-130` |
| 持久化适配器 | Persistence adapter | The `infrastructure` package's JPA entities and repositories used by application services. | `modules/awn-order/src/main/java/site/awn/order/infrastructure/OrderRepository.java:13-44`; `modules/awn-inventory/src/main/java/site/awn/inventory/infrastructure/InventoryReservationRepository.java:15-57` |
