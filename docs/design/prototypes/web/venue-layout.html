场馆事实

数据来源与重建声明

本原型只使用两个样本的场馆级公开事实，布局由本仓自行整理重建，不是官方图纸，也没有复制任何第三方仓的数据文件：

· 虹口足球场：座位数 33,060（信息框）/ 35,000（正文，两口径并存不择一）· 看台 22 · 包厢 47 · 场地 105×70m · 占地面积 56,000m² / 建筑面积 72,000m² · 来源 zh.wikipedia.org/wiki/虹口足球场（查阅 2026-10-16）

· 上海体育馆（万体馆）：体育比赛 12,000 座 / 文艺演出 10,000 座 · 内场表面为地板 · 来源 zh.wikipedia.org/wiki/上海体育馆（查阅 2026-10-16）

场馆名称为真实名称，未使用任何第三方商标或图片素材；看台排布、内场轮廓均为示意，点击任意看台可看该样本明确未公开的字段清单。

样本数据（过 schema 校验）

样本落在 docs/data/venues/，随附 schema.json 与零依赖校验脚本 validate.mjs：

node docs/data/venues/validate.mjs → 4 份样本全部 PASS（虹口足球场 / 万体馆 / 浦东足球场 / 上海体育场）

校验同时固化一条缺口断言：样本 17 个字段中 14 个在当前数据库 schema 里无处落库（venue 表仅有名称 / 城市 / 地址 / 坐标 / 地图图），座席表是场次级且无几何。详见 docs/design/venue-layout-schema.md。

红线：容量与分区只取公开可查数值，不编造精确座位号；校验脚本对样本含 sections / rows / seats 字段直接判 FAIL。
