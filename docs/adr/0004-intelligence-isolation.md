# ADR-0004：票务情报与交易数据严格隔离

- 状态：已接受
- 日期：2026-10-11

## 背景

AWN 的情报能力（价格趋势、渠道观察）是产品特色，但如果情报数据能够写入交易表，会污染库存与订单的可信度。

## 决策

- 情报数据走独立链路：采集调度器 → 来源适配器 → 原始观察 → 标准化与去重 → 质量检查 → 历史与分析。
- 初期共享 PostgreSQL 实例，但使用**独立 Schema 与独立数据库角色**。
- 情报角色的数据库权限**不包含**订单、库存、支付、退款表的写入。
- 情报接口只输出标准化观察结果与分析数据；外部页面的余票状态**不得**转换为 AWN 库存。
- 每条观察记录保留 `source_id`、`normalization_version`、`quality_status` 等溯源字段。

## 后果

- 正面：交易数据可信度不被破坏；情报采集故障不影响交易。
- 负面：需要维护两套数据库角色与权限；数据量增长后可将情报库独立部署。
