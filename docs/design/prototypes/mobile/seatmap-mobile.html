手势交互说明
  • 单指拖动：平移座位画布，边界回弹。
  • 双指捏合：以手势中心缩放，范围 0.6x–3x。
  • 双击：快速放大一级，再次双击复原。
  • 点按座位：选中 / 取消；已选上限 4 张（示例规则）。
  • 长按座位：查看座位号与票档价格气泡。

降级说明
  • 低端机 / 画布离屏：自动回退 2D 静态渲染，关闭缩放动效。
  • 3D 模式仅提供线框预览，待 2D 版本验收通过后再开放实色渲染。
  • 弱网：先渲染座位框架，座位状态分批拉取并增量刷新。
  • 掉帧检测：连续 2 秒低于 45fps 自动降级并上报。
